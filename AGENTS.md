# avi-skills

Author workflows in skill-sources, shared guidance in standards, and client syntax in adapters. The catalog defines package membership and dependencies. Preserve legacy migration commands and script interface. Run npm run build and npm run verify after changes; generated skills/plugins are committed installation surfaces. Node.js 24 LTS is required.
