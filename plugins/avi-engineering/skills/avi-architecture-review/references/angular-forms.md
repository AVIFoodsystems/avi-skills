# Angular form selection

Maintainer: AVI repository maintainers. Extracted 2026-10-12.
Status is recorded per rule; adopted means carried forward from the source standards, not a new team approval.

## AVI-FORMS-001

Status: **adopted**. Applicability: Maintaining forms.

Preserve the feature's Reactive Forms or Formly architecture unless migration is requested. Select Signal Forms for a new feature only after confirming installed-version support and suitability; its experimental status is version-dependent. Do not upgrade framework dependencies merely to fit a skill example.

## AVI-FORMS-002

Status: **adopted**. Applicability: Form implementation.

Keep validation and domain types consistent with the current form architecture. Preserve submit, disabled, pending and error behavior, and supply accessible labels and validation feedback. Test meaningful validation and submission behavior with the existing runner.
