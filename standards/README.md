# Shared AVI standards

These focused references extract reusable guidance from avi-web architecture documents. [registry.json](registry.json) records stable rule IDs, status, applicability, maintainer and source URLs. Adopted rules carry forward explicit source standards; they do not imply newly reviewed team approval. Recommendations and unverified examples remain non-normative.

Repository facts and scoped exceptions belong to consuming repositories. An exception should identify rule IDs, affected paths, rationale and conditions. Existing code supplies evidence, not automatic permission to override a standard. Client instruction precedence varies; AVI guidance does not change a client's own rules.

Author canonical standards here and workflows in skill-sources. Generated skill references are copied by the build; never edit those copies. See [maintenance](../docs/maintenance.md) for review and release responsibilities.
